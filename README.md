# Brand Promotion Website

A responsive brand promotion website built using **HTML & CSS**, featuring smooth animations and a modern, clean design to effectively showcase brand identity.

## 🚀 Features

- Fully responsive design (mobile, tablet & desktop)
- Smooth CSS animations & transitions
- Clean and modern UI
- Fast loading (no heavy frameworks)
- Cross-browser compatible

## 🛠️ Built With

- HTML5
- CSS3
